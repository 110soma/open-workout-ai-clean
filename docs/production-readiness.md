# Private Production readiness

Production promotion is not part of this OSS-candidate work.

Before promotion, complete several normal workouts on the protected Preview and confirm: local save, active reload, temporary offline input, reconnection sync, no duplicate session/set, complete staging, Google Sheets readback match, and “officially saved” status.

Prepare both the new Production deployment and the currently known good deployment ID. Rollback means reassigning the stable Production URL to the known good deployment; it does not mean deleting workout records.
