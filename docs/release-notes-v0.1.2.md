# Open Workout AI v0.1.2

種目タブの重量推移を見やすくする更新です。トレーニング入力・保存・同期の仕様は変更していません。

## 主な改善

- 日ごとの最高重量を、kg目盛りと日付付きの折れ線で表示。
- 「直近6回／3か月／半年／1年」の期間切替。直近6回は、その種目を実施した直近6日分です。
- 横軸は実際の日付間隔。日付ラベルを間引いても、記録点は保持します。
- 左・右は別系列。色に加えて丸／四角・実線／破線で区別します。
- グラフのタップ・クリック、または記録日の選択欄から、その日の重量・回数・RIR・左右を確認できます。
- 同日に複数回実施した場合は日ごとに集約し、詳細ではトレーニングごとに分けます。
- 未入力の重量は0kgへ置き換えません。RIR未入力もそのまま表示します。
- sideと左右方式がともに未記載の場合は「左右未記載」。左右同時と推測しません。
- 画面のバージョン表示を、公開版の番号と自動でそろえるようにしました。

## はじめて使う場合

[日本語の導入ガイド](https://github.com/110soma/open-workout-ai-clean/blob/v0.1.2/docs/setup.md)を上から進めてください。

Node.js 22以上を用意し、ZIPを展開したアプリフォルダで、Windows PowerShellから以下を実行します。

```powershell
npm.cmd ci
npm.cmd run dev
```

表示されたPC内のURLをブラウザで開きます。Supabase未設定なら架空データのDemoで起動し、外部へ記録を送信しません。通常のDemoには過去の重量推移用履歴がないため、グラフは「記録なし」で表示されます。

## 更新方法

新しいmigration（データベースの設計変更ファイル）や環境変数は不要です。サーバーを停止し、ソースを更新して `npm.cmd ci` を実行し、再起動してください。自分の `.env.local` とブラウザ内の保存データを削除しないでください。

## 制約・安全上の注意

- グラフは保存済みの種目別履歴を使用します。重量だけで筋力・筋肥大の向上を断定するものではありません。
- 明示されたウォームアップは集計対象外。セット種別未記載は勝手に補完しません。
- 独立した第三者による新規Supabase導入は未実地確認です。導入時は `VITE_WORKOUT_RECORD_MODE=test`、`VITE_AUTO_FINALIZE=false` を維持してください。
- Google Sheets連携は任意・実験的・初期状態OFFです。基本セットアップには不要です。
- スマートフォン向け公開環境の整備（Issue #4）は今回の更新に含みません。
- 既知のブラウザ用ファイルサイズ警告は残ります。公開に必要なビルドは成功しています。
- 管理用Secretを `VITE_*` やブラウザへ入れないでください。

v0.1.0・v0.1.1のタグとReleaseはそのまま残します。追加の配布ファイルはなく、GitHubのソースコードZIPだけを配布します。
